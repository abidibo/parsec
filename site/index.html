Pipes

Ctrl+Enter hands a result on to the next verb, and a $ stage runs in the background and hands on its output. Send a crashing container's logs to Claude, or turn your staged changes into a commit message, without copying a thing.

Quick Look

A pane slides in beside the results: images, text, a folder's contents, a project's README rendered as Markdown with its git state.

Instant

A resident Rust daemon with a GTK 4 window, already running before you press the key. No network calls while you type.

Follows you

Your editor, terminal and project folders are detected on first run and written to one config file you can carry between machines.

GNOME through and through

libadwaita and Wayland first. An optional Shell extension adds window switching and pastes straight into the window you came from.

Updates in one click

Parsec checks for new releases and plugin updates once a day. Update from Settings with a click: see what changed in each plugin first, and Parsec restarts itself on the new version.

Hackable

Plugins in any language.

A plugin is a small program that reads JSON lines on stdin and writes them on stdout. Results can stream as they're written, preview Markdown, and use the clipboard. Install one from a git URL, and Parsec keeps it up to date.

Ask ask fixAsk Claude, or fix and rewrite the text you copied. Voice sayDictate. Whisper transcribes it offline and pastes it in. Translator trTranslate text with free services, no account needed. Dev toolbox devUUIDs, Unix time, JWTs, colours, base64 and hashes.
~/.local/share/parsec/plugins/dice
import json, random, sys

for line in sys.stdin:
    msg = json.loads(line)
    if msg["type"] == "query":
        n = str(random.randint(1, 6))
        item = {"title": f"You rolled {n}",
                "actions": [{"label": "Copy", "copy": n}]}
        reply = {"type": "results", "id": msg["id"],
                 "items": [item]}
    elif msg["type"] == "init":
        reply = {"type": "ready"}
    else:
        reply = {"type": "ok"}
    print(json.dumps(reply), flush=True)
name = "Dice"
keywords = ["roll"]
exec = "main.py"
icon = "applications-games-symbolic"
